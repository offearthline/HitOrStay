# HIT, STAY

숫자 카드의 합을 한계 숫자에 맞춰 칩을 따내고 살아남는 멀티플레이 카드 게임. 시스템이 딜러를 맡습니다.

## 실행

```bash
npm install
npm start        # http://localhost:3000  (PORT 환경변수로 변경 가능)
npm test         # 게임 엔진 테스트
```

1. 닉네임 입력 → **새 방 만들기** → 4자리 방 코드 / 초대 링크 공유
2. 다른 플레이어는 코드(또는 링크)로 입장 (2~8명)
3. 방장이 **게임 시작**

같은 브라우저에서도 탭마다 다른 플레이어로 접속할 수 있습니다(세션은 탭 단위). 새로고침하면 같은 자리로 재접속됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/game.js` | 게임 엔진 (순수 상태 기계: 규칙, 베팅, 승부, 플레이어별 숨김 처리 뷰) |
| `server.js` | Express + Socket.IO. 방 관리, 재접속, 라운드 자동 진행, 연결 끊긴 플레이어 자동 처리 |
| `public/` | 웹 클라이언트 (빌드 없는 바닐라 JS) |
| `test/game.test.js` | 규칙 단위 테스트 + 무작위 300게임 시뮬레이션(칩 보존·한도·종료 검증) |

## 규칙 해석 (원문에 명시되지 않아 정한 부분)

- **공개 카드**: 3장을 받은 뒤 각자 공개할 1장을 직접 고릅니다. 모두 고르면 1차 베팅 시작.
- **베팅 한도**: 라운드 시작 시점의 최저 보유 칩 수가 그 라운드에서 한 사람이 낼 수 있는 베팅 총액(기본 베팅 포함)의 상한입니다. 그래서 콜은 항상 가능하고 올인/사이드팟이 없습니다.
- **기본 베팅 > 최저 보유 칩**이면 그 라운드 기본 베팅은 최저 보유 칩 수로 낮춰집니다.
- **베팅 라운드**: 포커식. 콜(더 낼 게 없으면 체크) / 레이즈 / 포기. 레이즈가 나오면 나머지 전원이 다시 응답해야 끝납니다.
- **HIT/STAY**: 선부터 한 명씩 돌아가며 1장씩. 한 번 STAY하면 그 라운드에서는 더 받지 않습니다. 초과해도 −1 카드를 노리고 계속 HIT할 수 있습니다(초과 판정은 공개 시점).
- **승부**: 초과하지 않은 사람 중 합이 가장 높은 쪽 → 같으면 카드 많은 쪽. 그래도 같으면 무승부로 균등 분배, 나머지는 선 플레이어에 시계 방향으로 가장 가까운 승자가 모두 가져갑니다. 전원 초과면 전원 무승부.
- **포기로 1명만 남으면** 그 자리에서 팟을 가져가고 라운드 종료.
- **덱**은 매 라운드 새로 섞습니다.
- **탈락 순위**: 같은 라운드에 여러 명이 0개가 되면 공동 순위.
- **나가기**: 게임 중 나가면 진행 중 라운드는 포기, 라운드 종료 시 탈락 처리.
- **연결 끊김**: 20초 이상 끊긴 플레이어 차례는 자동 처리(첫 장 공개 / 체크 가능하면 체크, 아니면 포기 / STAY).
- 규칙 5의 "피스 ↔ 칩 1:1 교환"은 화면상 칩 30개로 단순화했습니다.
